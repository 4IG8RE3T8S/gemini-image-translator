🧪 Gemini Image Translator — Comprehensive Test Suite

รวบรวมและจำลองโครงสร้างรูปภาพบนเว็บไซต์จริง 6 รูปแบบ เพื่อทดสอบความครอบคลุมของ Translation Pipeline

Case 1: Standard <img> Basic
แท็ก <img src="..."> มาตรฐานทั่วไป ตรวจสอบการโหลด การคำนวณตำแหน่ง และการแทนที่ภาพ
⚪ ยังไม่ได้ทดสอบ
Case 2: Responsive srcset Edge Case
แท็ก <img srcset="..."> เบราว์เซอร์จะให้ลำดับความสำคัญกับ srcset เหนือ src หากเปลี่ยนแค่ src ภาพจะไม่เปลี่ยน
⚪ ยังไม่ได้ทดสอบ
Case 3: <picture> + <source> Edge Case
โครงสร้าง <picture> ที่มีแท็ก <source srcset="..."> ครอบอยู่ การเปลี่ยน img.src จะไม่แสดงผลเพราะเบราว์เซอร์เรนเดอร์จาก source
⚪ ยังไม่ได้ทดสอบ
Case 4: Lazy Load + Observer Observer Reversion
รูปที่ใช้ loading="lazy" พร้อม data-src และจำลองสคริปต์ LazyLoad (ตรวจจับ MutationObserver เพื่อ revert กลับหากไม่ได้ระวัง)
⚪ ยังไม่ได้ทดสอบ
Case 5: CSS background-image No <img> tag
รูปภาพที่กำหนดผ่าน CSS background-image: url(...) บน <div> โดยไม่มีแท็ก <img>
CSS background-image (DIV)
⚪ ยังไม่ได้ทดสอบ
Case 6: Strict CSP Simulation Security Restricted
จำลองหน้าเว็บที่มี CSP เข้มงวด ไม่อนุญาต data: ใน img-src (บล็อกการ assign data: base64 ลง img.src)
⚪ ยังไม่ได้ทดสอบ
