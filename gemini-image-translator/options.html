Gemini Image Translator 🛡️ ปลอดภัย (Proxy Mode)

เชื่อมต่อผ่าน Backend Proxy Server เพื่อป้องกันการรั่วไหลของ Gemini API Key

1. เซิร์ฟเวอร์และยืนยันตัวตน (Backend & Auth)

ใส่ URL ที่ได้จาก Render (เช่น https://xxx.onrender.com) หรือเซิร์ฟเวอร์ในเครื่อง
Token ยืนยันตัวตนกับเซิร์ฟเวอร์ (สามารถกรอกเองหรือเข้าสู่ระบบด้านล่าง)
หรือเข้าสู่ระบบเพื่อขอ Token อัตโนมัติ

2. การแปลภาษา (Translation Settings)

ชื่อรุ่นโมเดล Gemini เช่น gemini-2.5-flash หรือ gemini-1.5-flash
