Gemini Image Translator 🛡️ ปลอดภัย (Proxy Mode)

เชื่อมต่อผ่าน Backend Proxy Server เพื่อป้องกันการรั่วไหลของ Gemini API Key

1. เซิร์ฟเวอร์และยืนยันตัวตน (Backend & Auth)

ใส่ URL ที่ได้จาก Render (เช่น https://xxx.onrender.com) หรือเซิร์ฟเวอร์ในเครื่อง
Token ยืนยันตัวตนกับเซิร์ฟเวอร์ (สามารถกรอกเองหรือเข้าสู่ระบบด้านล่าง)
หรือเข้าสู่ระบบเพื่อขอ Token อัตโนมัติ

2. การแปลภาษา (Translation Settings)

ชื่อรุ่นโมเดล Gemini เช่น gemini-2.0-flash หรือ gemini-1.5-flash
ค่าเริ่มต้น: 8192 เพื่อป้องกันปัญหา Gemini ตัดทอนข้อความ JSON ในรูปภาพที่มีหลายกล่องข้อความ
เลือกระหว่าง: Blur (กระจกฝ้าบังข้อความเก่าแต่เห็นภาพ), Solid (พื้นหลังทึบกระชับพอดีคำ), หรือ Transparent (โปร่งใส 100% ขอบขาว)

3. สำรองการแปลเมื่อ Token หมด (Google Translate Fallback)

เมื่อ Gemini API ติดปัญหาโควต้าเต็ม (HTTP 429 Rate Limit) ระบบจะเสนอทางเลือกหรือสลับไปใช้ Google Translate Images
ระบบจะทำการแปลและแสดงผลซ้อนทับภาพ (In-Place Overlay) บนหน้าเว็บเดิมให้ทันที โดยไม่ต้องเปิดแท็บใหม่
เช่น th (ไทย), en (อังกฤษ), ja (ญี่ปุ่น), zh-CN (จีน)

4. การส่งคำขอซ้ำอัตโนมัติ (Exponential Backoff Retry)

เมื่อคำขอล้มเหลวจาก Rate Limit (HTTP 429) หรือปัญหาเครือข่าย/เซิร์ฟเวอร์ชั่วคราว (HTTP 5xx) ระบบจะหน่วงเวลาและลองใหม่อัตโนมัติ
จำนวนครั้งสูงสุดที่จะส่งคำขอซ้ำก่อนยอมแพ้หรือสลับไปใช้โหมด Fallback (ค่าเริ่มต้น: 3 ครั้ง)
เวลาหน่วงเริ่มต้นเป็นวินาที (ค่าเริ่มต้น: 2 วินาที ซึ่งจะหน่วงเวลา 2, 4, 8 วินาที ตามลำดับแบบทวีคูณ)
